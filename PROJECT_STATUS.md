- **Engineering status:** No product build is authorized. No standalone
  MVP, no Gate 1, no further prototype work on `prototype/` or
  `spikes/web/`.
- **Retained asset:** The Signal → Evidence → Decision → THE MOVE method
  remains in active use, but inside the existing Soroush OS Notion
  Intelligence + Decisions workflow — not as a separate application.

## Reopening condition

This decision reopens **only** if new external evidence shows a repeated
need that the existing Notion workflow cannot satisfy without material
friction. A better idea, renewed enthusiasm, or a partial statistical
result closing (e.g., someone finally running the Q3 template comparison)
is not on its own a reopening condition — it would have to show the
existing Notion workflow is actually failing in practice.
